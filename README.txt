WILD DUEL

Open index.html in any modern browser.

To send it as a website:
1. Create a free GitHub repository.
2. Upload index.html.
3. Open Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select main / root and save.
6. GitHub will give you a shareable website link.

Game rules in this version:
- 2-player pass-and-play.
- Random shuffle every game.
- Chaos Deck has extra +2, +4, Skip, Reverse, and Wild cards.
- +2 can stack on +2, +4 can stack on +4 when stacking is enabled.
- Reverse acts like Skip in a 2-player game.
- First player to empty their hand wins.
